One day. One connected workflow.

Adjust the clock for your class, but keep the order: each part creates the context for the next one.

Opening

GitHub as a collaboration system

Tour the repository, name a project idea, and establish the no-secrets rule.

Part 01

Repositories and README conventions

Learners create a project boundary that tells a new contributor what to do next.

Part 02

Commits and branches

A small, isolated change becomes a reviewable unit of work.

Break

Reset and pair up

Match learners for the pull request review exercise.

Part 03

Pull requests and review

Turn a branch into a proposal, ask a question, respond to feedback, and merge.

Part 04

Issues, Projects, and Actions

Connect planning with a lightweight automation check.

Close

Final challenge and reflection

Ship one small improvement and explain the workflow in plain language.

Facilitator move

Demonstrate once, then let learners repeat the action. Ask what the action is protecting or making visible before moving on.

Outputs by the end

  • ✓A focused commit
  • ✓A non-default branch
  • ✓A reviewed pull request
  • ✓An actionable issue and Project item
  • ✓An inspected Actions result
