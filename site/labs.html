Practice path

Four labs, one habit: make intent visible.

Use your own small project or a fork of this course repository. Keep every change safe, focused, and easy for another person to understand.

LAB 01

Repository basics

30–40 min

Create a repository that explains itself. Add a README, a project file, an appropriate ignore file, and a useful description.

Success check

  • □Purpose and next action are clear.
  • □A .gitignore exists.
  • □A meaningful commit is visible.
Read the full lab →
LAB 02

Commits and branches

35–45 min

Create a branch, add a safe learner profile, and compare the branch with the default branch before anything is merged.

Success check

  • □Branch name describes the work.
  • □Default branch stays unchanged.
  • □Commit is focused and actionable.
Read the full lab →
LAB 03

Pull requests

45–60 min

Open a proposal, explain intent and verification, receive a useful review comment, and decide whether to merge.

Success check

  • □PR title and description explain the change.
  • □A specific review comment is present.
  • □There is a clear merge or next step.
Read the full lab →
LAB 04

Issues, Projects, and Actions

45–60 min

Write an actionable issue, organize it in a Project, and inspect the workflow that validates required course files.

Success check

  • □Acceptance criteria are testable.
  • □Issue is organized in a Project.
  • □Workflow trigger and result are explainable.
