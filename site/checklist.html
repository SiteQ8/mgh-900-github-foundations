Before class

Prepare

  • □Sign in to a GitHub account you can use for practice.
  • □Open the course repository and course site.
  • □Choose a small, non-sensitive project idea.
  • □Choose the web editor, GitHub Desktop, or local Git.
  • □Confirm that no secrets or private data will enter the repo.
During class

Practice

  • □Make one meaningful commit.
  • □Create and use a non-default branch.
  • □Open a pull request with intent and verification.
  • □Give or receive a specific review comment.
  • □Create an actionable issue with acceptance criteria.
  • □Organize the issue in a Project.
  • □Inspect and explain an Actions result.
