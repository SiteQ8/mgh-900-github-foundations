# MGH-900: GitHub Foundations

**Course date:** September 10, 2026  
**Format:** One-day, practice-first workshop

This is the student workspace for learning GitHub by using it. You will create a repository, make a focused change, collaborate through a pull request, track work with an issue and Project, and read a basic GitHub Actions workflow.

## Your course route

| Part | What you will do | Start here |
| --- | --- | --- |
| 1 | Create a repository that explains itself | [Lab 01](labs/01-repository-basics.md) |
| 2 | Make a focused change on a branch | [Lab 02](labs/02-commits-and-branches.md) |
| 3 | Open, review, and merge a pull request | [Lab 03](labs/03-pull-requests.md) |
| 4 | Track work and inspect automation | [Lab 04](labs/04-issues-projects-actions.md) |
| 5 | Complete the full workflow | [Final challenge](challenge.md) |

## Before class

- Sign in to a GitHub account you can use for practice.
- Open the course site and this repository.
- Bring a small, non-sensitive project idea.
- Choose the web editor, GitHub Desktop, or local Git. All three are fine.
- Never use passwords, API keys, private customer data, or confidential files in the exercises.

## Definition of done

You are ready to leave when you can point to:

- one meaningful commit;
- one branch that is not the default branch;
- one pull request with a clear description and review comment;
- one issue with testable acceptance criteria;
- one Project item in the right status; and
- one Actions result you can explain in plain language.
