# Lab 02 — Commits and branches

**Time:** 35–45 minutes  
**Goal:** Make an isolated, explainable change.

## Scenario

The default branch should remain usable while you work on a new idea. You will add a short learner profile without changing the default branch directly.

## Tasks

1. In your practice repository, create a branch named student/<your-name>.
2. Open starter/profile.md, copy it into your practice repository if needed, and replace the placeholders with safe, non-sensitive information.
3. Keep the change focused: edit only the profile file.
4. Commit with a message such as Add learner profile.
5. Compare your branch with the default branch and identify the changed file.
6. Return to the default branch and confirm that your change is not there yet.

## Commit quality test

A useful commit answers three questions: What changed? Why does this change belong together? Could a reviewer understand it without opening ten unrelated files?

## Success check

- [ ] The branch has a descriptive name.
- [ ] The default branch is unchanged.
- [ ] The commit contains one focused change.
- [ ] The commit message uses an action verb.
- [ ] The change contains no secrets or sensitive information.
