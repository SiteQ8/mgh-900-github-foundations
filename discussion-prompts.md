# Discussion prompts

Use these during transitions, pair work, or the closing reflection.

## Repository design

- What should a stranger understand within 30 seconds of opening your repository?
- Which information belongs in the README, and which belongs in an issue?
- What is the smallest useful contribution a new learner could make?

## History and change

- What makes two edits belong in the same commit?
- When is a branch worth creating?
- What makes a commit easy to undo or review?

## Collaboration

- What is the difference between asking for review and asking for permission?
- Which review comment would help without prescribing an unnecessary rewrite?
- What evidence should a PR include before it is merged?

## Planning and automation

- What makes an issue actionable?
- Which status in a Project tells the truth about the work?
- What should a workflow check automatically?
- What decisions should never be delegated to a green checkmark?
