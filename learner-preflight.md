# Learner preflight

Complete this before the workshop begins.

## Access

- [ ] I can sign in to GitHub.
- [ ] I know which email or account I will use for class.
- [ ] I can open the course repository.
- [ ] I know whether I will use the web editor, GitHub Desktop, or Git locally.

## Practice project

Write down one small, non-sensitive project idea:

- Project name: 
- Who would use it: 
- One improvement I could make in 30 minutes: 

## Safety check

- [ ] I will not use real passwords, API keys, private customer data, or confidential work files.
- [ ] I know that deleting a secret from a commit does not revoke it.

## Success target

By the end of class I want to be able to:

- [ ] create a focused commit;
- [ ] work on a branch;
- [ ] open and review a pull request; and
- [ ] explain one automation result.
