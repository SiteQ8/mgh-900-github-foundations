# Contributing to the course repository

This repository is designed for learning. Contributions should make the material clearer, safer, or easier to practice.

## Before opening a pull request

- Keep changes focused and explain the learning goal.
- Do not include passwords, API keys, private data, or copyrighted material you do not have permission to share.
- Check links and Markdown formatting.
- Use the pull request template.
- Be specific and respectful in review comments.

## Suggested contribution types

- Clarify a confusing instruction.
- Fix a broken link or typo.
- Add an accessible example.
- Improve an exercise's success check.

Small improvements are welcome; explain larger changes in an issue first.
