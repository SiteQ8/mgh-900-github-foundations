The route

Learn the objects by moving through them.

Each activity leaves evidence behind. By the end, you have a small workflow you can explain—not just a list of terms you can repeat.

01 / ORIENT

Make a repository explain itself.

Purpose, README, ignored files, and a first useful commit.

 02 / CHANGE

Work safely on a branch.

Make a focused change without destabilizing the default branch.

 03 / COLLABORATE

Turn change into a conversation.

Open, review, improve, and merge a pull request.

 04 / OPERATE

Plan and automate the work.

Connect issues, Projects, and a basic Actions workflow.
What good looks like

A collaborator can find the next step.

The course treats GitHub as a system for shared judgment: clear history, visible intent, useful review, and automation that stays understandable.

Before you arrive

  • □Sign in to a GitHub account you can use for practice.
  • □Bring a small, non-sensitive project idea.
  • □Choose the web editor, GitHub Desktop, or local Git.
  • □Know the safety rule: never commit secrets.
