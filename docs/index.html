The course route

Four moves that compound.

LAB 01 / ORIENT

Make a repository explain itself.

Purpose, README, ignored files, and a first useful commit.

LAB 02 / CHANGE

Work safely on a branch.

Make a focused change without destabilizing the default branch.

LAB 03 / SHARE

Turn change into a conversation.

Open, review, improve, and merge a pull request.

LAB 04 / OPERATE

Plan and inspect automation.

Connect issues, Projects, and an Actions validation check.

When you are stuck: make the change smaller, read the current state, describe what you expected, and ask a specific question. The goal is not to click faster; it is to make the next decision clearer.
