Practice path · follow in order

Choose a small project. Follow the route.

Every lab leaves you with an artifact. Do not wait for the perfect idea; use a safe, small improvement and let the workflow do the teaching.

Recommended rhythm: read the goal, make the smallest useful change, check your work, then explain it to a partner before moving on.

01LAB 01 / ORIENT

Repository basics

30–40 minStart here

Create a repository that explains itself. Add a README, a project file, an appropriate ignore file, and a useful description.

Done when

  • □Purpose and next action are clear.
  • □A .gitignore exists.
  • □A meaningful commit is visible.

02LAB 02 / CHANGE

Commits and branches

35–45 minWork safely

Create a branch, add a safe learner profile, and compare the branch with the default branch before anything is merged.

Done when

  • □Branch name describes the work.
  • □Default branch stays unchanged.
  • □Commit is focused and actionable.
