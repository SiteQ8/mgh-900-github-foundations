When you are stuck

Use the four-step reset.

Most GitHub confusion gets smaller when you slow down and make the current state visible.

Read

Check the branch, file, issue, or PR you are actually viewing.

Shrink

Reduce the change to the smallest safe experiment.

Describe

Say what you expected and what happened instead.

Ask

Turn the description into one specific question.

Safety reminder: public repositories are public. Use placeholders and sample data, never credentials or private information.
