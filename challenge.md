# Final challenge — Ship a small improvement

**Suggested time:** 30–45 minutes

Complete a small, end-to-end GitHub workflow in a practice repository.

## Choose one improvement

- Add a useful section to a README.
- Add a small example file.
- Improve a contributor instruction.
- Add a safe issue template or documentation example.

## Required workflow

1. Open an issue describing the improvement.
2. Create a branch with a descriptive name.
3. Make one or more focused commits.
4. Open a pull request that references the issue.
5. Ask for or perform a review.
6. Confirm the validation workflow passes.
7. Merge the PR, or leave it open with a written next step.
8. Update the Project status.

## Reflection

Write three short answers in the PR description:

- Which GitHub object helped you most: issue, branch, commit, PR, Project, or Action?
- What would you change before inviting an outside contributor?
- What is one habit you will carry into your next repository?

## Completion checklist

- [ ] Issue created.
- [ ] Branch created.
- [ ] Focused commit made.
- [ ] Pull request opened.
- [ ] Review completed.
- [ ] Action result inspected.
- [ ] Project status updated.
- [ ] Reflection written.
